# Ícone da aplicação

Símbolo **Audio**, U+E8D6, da fonte Segoe Fluent Icons do Windows, renderizado a
branco sobre fundo violeta para identificação da aplicação em temas claro e escuro.
Fonte: https://learn.microsoft.com/windows/apps/design/iconography/segoe-fluent-icons-font

`AppIcon.ico` contém tamanhos 16, 20, 24, 32, 40, 48, 64, 128 e 256 px.
É usado no executável e na janela. `AppIcon.png` é a pré-visualização a 256 px.
Para regenerar em Windows: `./scripts/New-AppIcon.ps1`.
O projeto inclui apenas o ícone renderizado, sem redistribuir a fonte.
