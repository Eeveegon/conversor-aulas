# Conversor de Audio de Aulas 0.1.1

Primeira release instalável para Windows x64.

- Conversão local de gravações M4A, AAC, WAV e outros formatos para Opus a 64 kbps VBR.
- Seleção de ficheiros ou pastas, subpastas opcionais e arrastar e largar.
- Frequências de 48 kHz (predefinida), 24 kHz e 16 kHz.
- Cópias na pasta original, com proteção contra substituição e cancelamento seguro.
- Interface nativa WinUI 3 com tema claro/escuro conforme o Windows e ícone de áudio.
- Correção do cursor no seletor de frequência.
- MSI e executável assinados digitalmente com certificado autoassinado e timestamp.

## Instalação

Descarrega `Conversor-de-Audio-de-Aulas-0.1.1-win-x64.msi` e executa-o.
Requer Windows 10 versão 2004 ou superior, ou Windows 11, em 64 bits.
O instalador inclui .NET, Windows App SDK e FFmpeg; não é necessário instalá-los
separadamente. Cria a entrada **Conversor de Audio de Aulas** no menu Iniciar e
na lista de aplicações instaladas. A instalação é para todos os utilizadores e
pode pedir autorização de administrador.

O certificado não é disponibilizado como ficheiro separado nesta release.
Como a assinatura é autoassinada, o Windows pode apresentar avisos de confiança ou SmartScreen.
O instalador não modifica automaticamente os certificados de confiança.

Consulta `SHA256SUMS.txt` para verificar a integridade do MSI e
`THIRD-PARTY-NOTICES.md` para a informação dos componentes incluídos.
Os originais nunca são apagados. Áudio já muito comprimido pode não ficar menor.
